# Phase 7 Gate 3 — Announcements Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Administrators publish school notices (whole school, one class or one section) that guardians with portal access read in the portal, and can then prepare one link-only WhatsApp message per guardian in the Gate 1 outbox.

**Architecture:** A new immutable `Announcement` model (database triggers like the other history tables) and a service module `core/announcements.py` holding every rule: publish, withdraw (also dismisses waiting messages), audience resolution (reusing the Gates 2/4 portal-access rule, generalised to many students), audience counts, what a guardian sees, and preparing messages through Gate 1's `enqueue()`. Thin office views (`core/announcement_views.py`) and portal views use it.

**Tech Stack:** Django 5.2, PostgreSQL (SQLite for quick runs), Django TestCase.

**Spec:** `docs/superpowers/specs/2026-10-15-phase7-gate3-announcements-design.md`

## Global Constraints

- Branch `phase-7/gate-3-announcements`, stacked on `phase-7/gate-2-4-alerts` (PR #51). Latest migration on that branch: `0059_seed_alert_templates`.
- WhatsApp text, exactly (template key `announcement`, v1, WHATSAPP, en, approved): `Dear parent, there is a new notice from the school. Read it here: {portal_url}`. Parameters: only `portal_url`. `student=None`. Idempotency subject: `f"announcement-{announcement.pk}"`.
- Administrators only: `core.add_announcement` (publish), `core.view_announcement` (list/detail), `core.withdraw_announcement` (withdraw), `core.send_notification` (prepare messages; Gate 1 permission, already granted). The three announcement permissions are granted to "School Administrators" by migration.
- Saving publishes; no drafts; no editing. Title ≤ 120 chars, body ≤ 2000 chars (enforced by validators, not only the form), both required (stripped). Audience `ALL` / `CLASS` / `SECTION`; exactly the matching FK set.
- History rules (DB triggers, PostgreSQL and SQLite): no DELETE; `public_id, title, body, audience, class_grade_id, section_id, published_by_id, published_at` never change; once `withdrawn_at` is set, `withdrawn_at, withdrawn_by_id, withdrawal_reason` never change.
- Audience members: students with an `AcademicEnrollment` effective on `core.models.business_today()` (call through the module so tests that patch it control it) in the matching class/section (any class for ALL). Recipients: the Gates 2/4 portal-access rule (active grant, not review-pending, active `GuardianAccount` with active user); one per guardian.
- Withdraw: reason required; PREPARED messages for that notice dismissed with reason exactly `Announcement withdrawn`; SENT ones untouched.
- Portal notice URL: `portal:notice` with the announcement's `public_id`; message link = `settings.PORTAL_BASE_URL + reverse("portal:notice", args=[public_id])`.
- Error texts, exactly: withdrawn notice → `This notice has been withdrawn.`; not ASSIST → `WhatsApp sending is switched off for this school.`; no portal address → `Set the portal address (PORTAL_BASE_URL) before sending WhatsApp messages.`; empty withdraw reason → `Give a reason for withdrawing this notice.`; already withdrawn → `This notice has already been withdrawn.`
- Body is rendered with `linebreaksbr` (autoescaped). No HTML input.
- Quick runs use SQLite: `env -u DB_NAME .venv/Scripts/python.exe manage.py test <label> --noinput`. Never run two Postgres suites at once.

```python
# --- Phase 7 Gate 3: announcements (ADR 0015) --------------------------------


class Announcement(models.Model):
    """A school notice for guardians. Immutable once published; withdrawn, never deleted.

    Published by administrators to the whole school, one Class/Grade or one
    Section; guardians with portal access read it in the portal. Database
    triggers refuse deleting a row, changing its content, and changing a
    withdrawal once recorded.
    """

    class Audience(models.TextChoices):
        ALL = "ALL", "Whole school"
        CLASS = "CLASS", "One class"
        SECTION = "SECTION", "One section"

    public_id = models.UUIDField(default=uuid.uuid4, unique=True, editable=False)
    title = models.CharField(max_length=120)
    body = models.TextField(validators=[MaxLengthValidator(2000)])
    audience = models.CharField(max_length=10, choices=Audience.choices)
    class_grade = models.ForeignKey(
        ClassGrade, on_delete=models.PROTECT, null=True, blank=True,
        related_name="announcements",
    )
    section = models.ForeignKey(
        Section, on_delete=models.PROTECT, null=True, blank=True,
        related_name="announcements",
    )
    published_by = models.ForeignKey(
        settings.AUTH_USER_MODEL, on_delete=models.PROTECT, related_name="+"
    )
    published_at = models.DateTimeField(default=timezone.now)
    withdrawn_at = models.DateTimeField(null=True, blank=True)
    withdrawn_by = models.ForeignKey(
        settings.AUTH_USER_MODEL, on_delete=models.PROTECT, null=True, blank=True,
        related_name="+",
    )
    withdrawal_reason = models.CharField(max_length=200, blank=True)

    class Meta:
        ordering = ["-published_at", "-pk"]
        permissions = [("withdraw_announcement", "Can withdraw an announcement")]
        constraints = [
            models.CheckConstraint(
                condition=models.Q(audience__in=["ALL", "CLASS", "SECTION"]),
                name="announcement_audience_valid",
            ),
            models.CheckConstraint(
                condition=(
                    models.Q(audience="ALL", class_grade__isnull=True, section__isnull=True)
                    | models.Q(audience="CLASS", class_grade__isnull=False,
                               section__isnull=True)
                    | models.Q(audience="SECTION", class_grade__isnull=True,
                               section__isnull=False)
                ),
                name="announcement_audience_target",
            ),
            models.CheckConstraint(
                condition=(
                    models.Q(withdrawn_at__isnull=True, withdrawn_by__isnull=True,
                             withdrawal_reason="")
                    | (models.Q(withdrawn_at__isnull=False, withdrawn_by__isnull=False)
                       & ~models.Q(withdrawal_reason=""))
                ),
                name="announcement_withdrawal_complete",
            ),
        ]

    def clean(self):
        super().clean()
        if self.audience == self.Audience.CLASS and not self.class_grade_id:
            raise ValidationError({"class_grade": "Choose the class."})
        if self.audience == self.Audience.SECTION and not self.section_id:
            raise ValidationError({"section": "Choose the section."})
        if self.audience != self.Audience.CLASS and self.class_grade_id:
            raise ValidationError({"class_grade": "Only a notice to one class has a class."})
        if self.audience != self.Audience.SECTION and self.section_id:
            raise ValidationError({"section": "Only a notice to one section has a section."})

    @property
    def is_withdrawn(self):
        return self.withdrawn_at is not None

    def audience_label(self):
        if self.audience == self.Audience.CLASS:
            return str(self.class_grade)
        if self.audience == self.Audience.SECTION:
            return str(self.section)
        return self.get_audience_display()

    def __str__(self):
        return self.title
```

```python
# Phase 7 Gate 3 (ADR 0015): announcements are history.
#
# No DELETE. Published content never changes. The withdrawal fields may be
# set once (from empty) and never changed or cleared afterwards.

from django.db import migrations

MESSAGE = "Announcements cannot be deleted or rewritten."
FIXED = [
    "public_id", "title", "body", "audience", "class_grade_id", "section_id",
    "published_by_id", "published_at",
]
WITHDRAWAL = ["withdrawn_at", "withdrawn_by_id", "withdrawal_reason"]


def _changed(columns, op):
    return " OR ".join(f"NEW.{c} {op} OLD.{c}" for c in columns)


SQLITE = [
    f"CREATE TRIGGER core_ann_no_delete BEFORE DELETE ON core_announcement "
    f"BEGIN SELECT RAISE(ABORT, '{MESSAGE}'); END;",
    f"CREATE TRIGGER core_ann_fixed BEFORE UPDATE ON core_announcement "
    f"WHEN {_changed(FIXED, 'IS NOT')} "
    f"OR (OLD.withdrawn_at IS NOT NULL AND ({_changed(WITHDRAWAL, 'IS NOT')})) "
    f"BEGIN SELECT RAISE(ABORT, '{MESSAGE}'); END;",
]
SQLITE_REVERSE = [
    "DROP TRIGGER IF EXISTS core_ann_no_delete;",
    "DROP TRIGGER IF EXISTS core_ann_fixed;",
]

POSTGRES = [
    f"""
    CREATE OR REPLACE FUNCTION core_ann_guard() RETURNS trigger AS $$
    BEGIN
        IF TG_OP = 'DELETE' THEN
            RAISE EXCEPTION USING ERRCODE = 'integrity_constraint_violation',
                MESSAGE = '{MESSAGE}';
        END IF;
        IF {_changed(FIXED, 'IS DISTINCT FROM')}
           OR (OLD.withdrawn_at IS NOT NULL AND ({_changed(WITHDRAWAL, 'IS DISTINCT FROM')}))
        THEN
            RAISE EXCEPTION USING ERRCODE = 'integrity_constraint_violation',
                MESSAGE = '{MESSAGE}';
        END IF;
        RETURN NEW;
    END;
    $$ LANGUAGE plpgsql;
    """,
    "CREATE TRIGGER core_ann_guard BEFORE UPDATE OR DELETE ON core_announcement "
    "FOR EACH ROW EXECUTE FUNCTION core_ann_guard();",
]
POSTGRES_REVERSE = [
    "DROP TRIGGER IF EXISTS core_ann_guard ON core_announcement;",
    "DROP FUNCTION IF EXISTS core_ann_guard();",
]


def forwards(apps, schema_editor):
    pg = schema_editor.connection.vendor == "postgresql"
    for statement in POSTGRES if pg else SQLITE:
        schema_editor.execute(statement)


def backwards(apps, schema_editor):
    pg = schema_editor.connection.vendor == "postgresql"
    for statement in POSTGRES_REVERSE if pg else SQLITE_REVERSE:
        schema_editor.execute(statement)


class Migration(migrations.Migration):
    dependencies = [("core", "0060_announcements")]

    operations = [migrations.RunPython(forwards, backwards)]
```

```python
    return list(Permission.objects.using(alias).filter(
```

```python
"""Phase 7 Gate 3: announcements (ADR 0015).

Spec: docs/superpowers/specs/2026-10-15-phase7-gate3-announcements-design.md.
Saving publishes; a published notice never changes and is withdrawn, not
deleted. Guardians with portal access to a student in the audience read it in
the portal; preparing WhatsApp messages is a separate administrator step.
"""

from django.core.exceptions import ValidationError
from django.db import transaction
from django.utils import timezone

from core.models import Announcement

TEMPLATE_KEY = "announcement"
WITHDRAWN_REASON = "Announcement withdrawn"


def publish(*, title, body, audience, class_grade=None, section=None, actor):
    announcement = Announcement(
        title=(title or "").strip(),
        body=(body or "").strip(),
        audience=audience,
        class_grade=class_grade if audience == Announcement.Audience.CLASS else None,
        section=section if audience == Announcement.Audience.SECTION else None,
        published_by=actor,
    )
    announcement.full_clean()
    announcement.save()
    return announcement


def withdraw(announcement, *, actor, reason):
    reason = (reason or "").strip()
    if not reason:
        raise ValidationError("Give a reason for withdrawing this notice.")
    with transaction.atomic():
        locked = Announcement.objects.select_for_update().get(pk=announcement.pk)
        if locked.is_withdrawn:
            raise ValidationError("This notice has already been withdrawn.")
        locked.withdrawn_at = timezone.now()
        locked.withdrawn_by = actor
        locked.withdrawal_reason = reason[:200]
        locked.save(update_fields=["withdrawn_at", "withdrawn_by", "withdrawal_reason"])
    return locked
```

```python
logger = logging.getLogger(__name__)


def notice_url(announcement):
    if not settings.PORTAL_BASE_URL:
        raise ValidationError(
            "Set the portal address (PORTAL_BASE_URL) before sending WhatsApp messages."
        )
    return settings.PORTAL_BASE_URL + reverse("portal:notice", args=[announcement.public_id])


def prepare_messages(announcement):
    """One link-only message per guardian; repeating prepares nothing new.

    Counts describe the audience's messages: an existing message (from an
    earlier click) counts as prepared, or skipped if it had no consent.
    """
    if announcement.is_withdrawn:
        raise ValidationError("This notice has been withdrawn.")
    if notifications.school_mode() != School.NotificationMode.ASSIST:
        raise ValidationError("WhatsApp sending is switched off for this school.")
    parameters = {"portal_url": notice_url(announcement)}
    result = {"prepared": 0, "skipped": 0, "failed": 0}
    for grant in recipient_grants(announcement):
        guardian = grant.student_guardian.guardian
        try:
            with transaction.atomic():
                message = notifications.enqueue(
                    guardian=guardian, student=None, type=Notification.Type.ANNOUNCEMENT,
                    template_key=TEMPLATE_KEY, parameters=parameters,
                    subject=f"announcement-{announcement.pk}",
                )
        except notifications.NotificationError as problem:
            logger.warning("ANNOUNCEMENT message not prepared (announcement %s, guardian %s): %s",
                           announcement.pk, guardian.pk, problem)
            result["failed"] += 1
            continue
        if message.status == Notification.Status.SKIPPED_NO_CONSENT:
            result["skipped"] += 1
        else:
            result["prepared"] += 1
    return result
```

```python
        text = (f"Messages ready on the To send page: {result['prepared']}. "
                f"Not sent (no WhatsApp consent): {result['skipped']}.")
        if result["failed"]:
            text += f" Could not prepare: {result['failed']}."
        messages.success(request, text)
    return redirect("core:announcement-detail", pk=pk)


@administrator_required("core.withdraw_announcement")
@require_POST
def announcement_withdraw(request, pk):
    notice = get_object_or_404(Announcement, pk=pk)
    try:
        announcements.withdraw(notice, actor=request.user, reason=request.POST.get("reason"))
    except ValidationError as problem:
        messages.error(request, problem.messages[0])
    else:
        messages.info(request, "Notice withdrawn. Guardians no longer see it.")
    return redirect("core:announcement-detail", pk=pk)
```
